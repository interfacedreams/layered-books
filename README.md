# Layered Books

Navigate a book using a nested bullet point outline generated by AI. Live at [layeredbookz.com](https://layeredbookz.com/).

Layers:

- Layer 1: chapter descriptions
- Layer 2: key points for each chapter
- Layer 3: key details for each key point
